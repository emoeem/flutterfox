# Voicefox UI 重设计 v2 · 设计规格（已冻结 v1.0）

> 状态：**已冻结（2026-11-28 用户确认方向 + 打磨轮落实）**。本文件是 R1 至 R6 批次的唯一视觉依据；实施期只允许缺陷级视觉修正，不再改变整体方向。
> 原型：`mockups/index.html`（6 屏：桌面 首页/发现/全屏播放页/队列、手机 首页/全屏播放页），整版截图 `mockups/board.png`
> 风格基调：现代简洁风（Catppuccin Mocha + Mauve 配色体系）。深蓝灰分层底色、大封面卡片、克制装饰、留白有序；氛围渐变只出现在播放页。
> 总纪律：不为视觉效果堆砌渐变、阴影、动画；保持克制、简洁、有质感。

## 1. 设计原则

1. **封面供色，界面持中性**：所有彩色来自封面；chrome（侧栏/顶栏/播放栏）保持蓝灰中性。
2. **一屏一强调**：强调色只给活跃态与主行动（当前页导航、播放按钮、正在播放指示、当前歌词行）。
3. **音源徽标是身份系统**：13 音源以 5px 色点 + 名称小徽标贯穿卡片/列表行/播放页。
4. **空态有主行动**：空态必须给出可执行动作（如「新建歌单」），禁止孤浮装饰按钮。
5. **诚实四态**：加载/空/错误/成功一律真实反馈，骨架屏优先。
6. **真实封面优先**：有真实专辑封面时展示原始封面不做过度处理；自动封面只在无封面时生成。

- 播放页氛围 wash：从封面取两团 blur 径向色块（左上 + 右下），不透明度不超过 0.18，仅全屏播放页使用；原型用 mauve + blue（`#89B4FA`）示意，运行时按封面主色生成。
- 播放按钮（底部栏大播放钮/播放页大播放钮/悬停播放钮/手机 Hero 播放钮）：accent 底 + 深色图标（`#191927`），不用白色按钮。
- 音源徽标色点：酷我 `#E8A15D`，酷狗 `#5DA8E8`，QQ `#6BC98A`，网易 `#E86B6B`，B站 `#F279A8`，千千 `#B98AE0`（其余音源归入 text-3）。

## 3. 字体与间距

- 字族：系统栈（PingFang SC / Noto Sans SC / Microsoft YaHei），单一字族走层级。
- 字阶：display 26-28/700 → 页题 22/700 → 区题 16/600 → 正文 13.5-14 → 说明 12-12.5 → 徽标 10.5。
- 行高：中文统一 1.4-1.5；数字（时间/计数）用 tabular-nums。
- 间距节奏 4px 基：页 padding 桌面 30 / 手机 18；卡片内 22-24；列表行水平 10-12。
- 圆角：卡片 10-14（封面卡 10、面板 14、大封面 16）；控件 8-9；徽标 4；全圆仅播放钮。
- 动效：页面过渡 180ms / 面板展开 240ms（沿用 `VxMotion` 数值，emphasized 曲线）；歌词切换 250ms 平滑过渡；切歌/封面切换加交叉淡入，克制不炫技。

## 5. 封面系统（差异化规则）

1. **真实封面优先**：`ArtworkResolver`/`VxArtwork` 链路不变，能取到真实封面一律原样展示。
2. **无封面时生成自动艺术封面**，四要素：
   - **稳定颜色组合**：按歌曲/专辑实体 id 的稳定 hash 从预定义 palette 组选取（同实体永远同配色）。
   - **渐变方向多样化**：至少 5 个方向槽位（115/140/165/45/200deg 等），hash 决定。
   - **柔和光影与模糊色块**：径向高光 + 暗角 + 1 个大 blur 形态（圆斑/圆环/横条三选一，hash 决定）。
   - **轻微颗粒纹理**：低透明度噪声叠加（约 0.06，overlay 混合）。
3. **禁止**：字母回退占位、全部封面同一紫色系、强锐利几何装饰。

## 7. 与现网的差异清单

1. 色板由紫罗兰偏色近黑 → Catppuccin Mocha 蓝灰分层，Mauve 仅作强调。
2. 卡片去 outlineVariant 边框 → tonal surface 层次；描边只留 line 一级（低对比灰紫）。
3. 封面回退从「字母+渐变」→ 差异化自动艺术封面（hash 稳定配色 + 方向 + 形态 + 颗粒）。
4. 我的歌单空态孤浮按钮 → 内联空态面板 + 主行动。
5. 播放页氛围取色背景为新增；比例改为 42:58。
6. 歌词区常驻「重新获取」入口（P2-17 落位）；当前歌词行用强调紫。
7. 播放钮统一 accent 底 + 深色图标（原白色按钮方案作废）。
