## 1. P0 · 阻断级（功能不可用 / 数据损坏）

| ID | 问题 | 证据 | 用户可见后果 |
|---|---|---|---|
| P0-01 | 应用层从不消费播放器 watcher：`state/position/duration` 三个 `watch::Receiver` 与 `take_event_receiver()` 只有测试替身实现 | `application/src/services/playback.rs` 无订阅；`application/src/state.rs:41,52` 恒为 `Duration::ZERO` | 进度条禁用、时间恒 0:00、seek 不可用、歌词不推进、`LivePlayback` 插值被 `duration>0` 挡住 |
| P0-02 | `Toggle` 既不写快照也不发事件 | `application/src/service.rs:178`（修前） | 点大播放按钮 UI 不刷新，图标/状态卡保持旧值 |
| P0-03 | `PlayerEvent::Ended` 无消费者 | `core/src/traits/player.rs:107`；`application/` 无 `take_event_receiver` | 一曲放完即停，自动下一首不存在 |
| P0-04 | 播放模式只写配置，后端无消费者；`Next/Previous` 取模轮转 | `application/src/service.rs:216-232` | 单曲循环/随机/顺序全部无效 |
| P0-05 | 无 `SetVolume` 通路；设置页音量只写配置；myune 音量条是空方法 | `ffi/src/lib.rs` 54 个命令无音量；`settings_page.dart:114-124`；`myune_seam/app_model_audio_backend.dart:178` | 所有音量控件是假控件 |
| P0-06 | **`ConfigDto` 往返损坏**：`format!("{:?}", play_mode)` 给 String 加引号，`apply_to` 原样写回 → 每次保存多一层转义；`download_quality` 输出 `High320` 但回写只匹配 `high320` → 静默降为 `Low128` | `ffi/src/lib.rs:173,185-187,209,219-224`（修前） | **实测 `~/.config/voicefox/config.toml` 已膨胀到 134 MB**，`play_mode` 是一行 128 MB 的转义引号；每次设置保存都要重写整个文件 |
| P0-07 | 错误全部静默：`dispatch()` 丢弃 `Result`；`SearchFailed/PlaybackFailed/Notification` 的 `message` 被丢弃；`lastNotification` 只在启动页和两个 snackbar 出现 | `app_model.dart:857-859,169-182` | 搜索失败、播放失败、登录失败、下载失败都无提示 |

| P0-09 | **16 套 seed 主题 + FlClash 定制的页面底色透明**：`hexOf` 返回 24 位值，`Color(0x1E1E2E)` 的 alpha=0x00 | `theme/seed_colors.dart:38`（修前） | `scaffoldBackgroundColor` = 透明 → 整页透出窗口纯黑；截图里 6 个页面背景全是 `#000000` |

### 实机新发现（不在原清单）

1. **配置损坏（P0-06）已在真机落地**：`~/.config/voicefox/config.toml` = 134,227,480 字节，`play_mode` 是 128 MB 的单行转义串。这会拖慢每次启动解析与每次设置保存。
2. **页面底色透明（P0-09）**：六个页面的背景像素均为 `#000000`，卡片是 `#3E3D40`。`hexOf` 丢了 alpha 位。
3. **窄窗索引错位**：桌面选中「设置」后把窗口缩到 390，底栏高亮「更多」但内容仍是设置页（`selectedIndex` 被 clamp 到 4，页面却按 `_index=5` 渲染）。
4. **收藏封面大量缺失**：9 首收藏只有 1 首有封面，其余是占位音符图标——库快照里的 `cover_url` 没被补齐。
5. **热门歌单横向列表裁切**：1440 下第 5 张卡被卡片右边界切掉，标题挤成 3 行。
6. **队列页无标题、左侧固定 380 栏**，右侧空态占满剩余宽度，信息密度极低。
7. **搜索页内容左右各留 ~200px 空白**（无约束的 Column/居中效果），与规格的 12/24 边距都不符。
8. **设置页主题卡标签普遍截断**（`Catppuccin L...`、`Midnight Co...`、`Material Base...`）。

## 5. 复现步骤

```bash
# 构建与运行
cd flutter && /opt/flutter/bin/flutter build linux --release
./build/linux/x64/release/bundle/voicefox_flutter

# P0-01：播放任意歌曲，观察首页/队列/播放页进度条与时间
# P0-02：点大圆播放按钮，观察图标是否变化
# P0-06：改任意设置后检查配置
grep -c 'play_mode' ~/.config/voicefox/config.toml   # 单行超长即中招
ls -lh ~/.config/voicefox/config.toml
# P0-09：取任意页面背景像素
magick screenshot.png -format '%[pixel:p{1300,500}]' info:   # 期望非 #000000
```
